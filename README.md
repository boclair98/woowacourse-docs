# woowacourse-docs

우아한테크코스 학습 자료, 코드리뷰 가이드, 프리코스 제출 방식, 클린코드 원칙 등을 모아둔 문서 저장소입니다.

개발 학습 과정에서 참고한 내용을 정리하고, 코드리뷰와 협업 문화를 이해하기 위한 자료를 한곳에 모으는 용도로 사용합니다.

| [코드리뷰 요청](./maincourse/README.md) | 코드리뷰 요청 방식과 리뷰 문화 관련 자료 |

## 저장소 목적

- 우아한테크코스 학습 흐름을 빠르게 찾아보기
- 코드리뷰와 클린코드 기준을 반복해서 확인하기
- Java 백엔드 학습 과정에서 참고한 문서 자산화하기

## 포트폴리오 메모

이 저장소는 실행 가능한 애플리케이션 프로젝트가 아니라 학습 문서 저장소입니다. 주요 프로젝트 README에서는 `학습 기록 및 코드리뷰 문화 이해`를 보여주는 보조 자료로 활용하는 것이 적절합니다.
